# Identidade Visual Creator Pro

Manual visual independente criado para o Creator Pro da Helena Steiger.

## Arquivos

- `index.html`: manual navegavel da identidade.
- `styles.css`: sistema visual, responsivo e com tokens de marca.
- `assets/creator-pro-logo.png`: logo principal.
- `assets/`: fotos usadas nas aplicacoes e mockups.

## Tipografia

- **Outfit**: titulos, chamadas, logo, botoes e estatisticas.
- **DM Sans**: textos corridos, descricoes, legendas e interface.

## Cores principais

- `--color-brown-900`: `#2C1810`
- `--color-brown-800`: `#3D2316`
- `--color-brown-600`: `#5E3A23`
- `--color-brown-400`: `#8B6243`
- `--color-nude-100`: `#FBF8F5`
- `--color-nude-200`: `#F5EDE6`
- `--color-primary`: `#D8C2AE`
- `--color-gold`: `#C5A76E`

## Direcao de uso

A identidade deve parecer premium, feminina, estrategica e acolhedora. Use fundos nudes como base, marrons para contraste e dourado apenas como detalhe de destaque.
